<img src="https://img.shields.io/badge/Spring_Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white"/>

Backend para gerenciamento de **pedidos e cobranças de e-commerce**, desenvolvido com foco em boas práticas e engenharia de software além de um CRUD tradicional.

### Principais conceitos aplicados

- Arquitetura modular por domínio
- APIs REST
- Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- Redis
- Flyway
- DTOs e validação
- Spring Security + JWT
- Global Exception Handler
- Arquitetura Hexagonal no módulo de pagamentos
- Testes com JUnit e Mockito
- Docker
- OpenAPI / Swagger
- Pull Requests
- Conventional Commits
- ADRs
- CI/CD
